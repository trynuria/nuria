# Changelog

## 0.2.1 — 2026-10-08

- Rebuilt the observatory around a full-width neural field and compact live instruments.
- Increased connection detail and depth separation; slowed measured spike replay for legibility.
- Added expandable input receipts, contextual action descriptions and selected action scores.
- Added chart axes, explicit input-source labels and compact formatting for large counters.
- Reserved component space across mobile, tablet and desktop layouts.

## 0.2.0 — 2026-10-08

- Added an independent 1,024-neuron circuit with reward-modulated plasticity, source-specific prediction, episodic memory and workspace competition.
- Added hybrid action selection, a software habitat and bounded experiments with measured outcomes.
- Added atomic cognitive checkpoints, spike records, matched perturbation probes and controlled neural evaluations.
- Prepared read-only treasury observation, durable spending reservations and unsigned payments; financial execution remains unconnected.
- Published the capability map and evaluation evidence, and added streaming encrypted backups with cognitive snapshots.
- Retained the original 256-neuron process and receipt history.

## 0.1.0 — 2026-10-07

Initial public source release of the Nuria observatory, continuous Brian2 model, finalized Pump/PumpSwap ingestion, evidence API and verification pipeline.

### Source review

- Standardized Python, JavaScript, CSS, HTML and JSON formatting.
- Made the documentation builder robust to formatted anchor markup.
- Added rejection of mismatched input-evidence arrays in local receipt verification.
- Replaced backup integrity assertions with explicit checks enforced under optimized Python execution.
- Moved the private backup destination to environment configuration.
- Corrected documentation of the trade reader's polling interval.
- Added deterministic protocol fixtures, corruption checks and neural recovery tests.
- Added pinned CI with read-only repository permissions and frontend rebuild checks.

These changes describe this source release. The live service remains on its previously deployed version.
