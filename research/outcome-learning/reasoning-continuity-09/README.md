# Matched reasoning-continuity comparison

The same execute/observe worker runs with either normal visible history or full
provider output-item replay. Model, task, prior experience, initial prompt,
native execution, maximum five calls and 7,200 output tokens per job match.
Opaque provider reasoning remains private; public evidence contains its hashes
and actual action/usage records, not its contents.

Before any task bodies were selected, metadata rules froze 72 source tasks.
The unchanged references pass for 70. Both unsupported cases remain recorded:
one depends on a pandas frequency alias removed from this runtime, and one
requires a denied network operation. Neither is replaced, and isolation is not
relaxed. The remaining tasks cover five available data-programming families;
earlier studies had exhausted eligible text and collection tasks under these
rules.

Both conditions receive 664 earlier checked outcomes. The two previously
identified contradictory timing jobs are withheld from that common experience.
No selected task overlaps it. Tasks are fresh within Nuria's history; this
public benchmark may occur in model pretraining, which remains unknown.

The prospective accuracy gate requires at least 70 valid pairs, four percentage
points of improvement, a one-sided exact paired p-value at most 0.0125 and no
family regression exceeding two tasks. All programs must commit publicly before
terminal checks. A failed gate stays failed. Lower cost or changed programs alone
will not be called an accuracy improvement.

Before primary inference, `prospective-amendment.json` records the shared change
from the earlier low-effort draft to the model's default medium effort. Selection,
history, output limits and all decision gates stay unchanged. The transport
qualification used low effort; no primary model outputs informed the amendment.

The four-call transport qualification confirms the returned `all_turns` context
and actual opaque-item replay in the candidate only. First requests match. It
also executes the proposed programs against an actual recording file. This is
wiring evidence, not a fresh intelligence comparison. Its exact source is kept
separately from the later known-truncation handling fix, covered by seven offline
tests.

The adapter uses the documented
[Responses reasoning-state interface](https://developers.openai.com/api/docs/guides/reasoning#preserve-reasoning-across-calls).
Its price envelope is limited to
[GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol), including
long-context/cache-write upper rates. No new model, framework, hosting or
server-managed agent session is required. Neither a successful wiring test nor
this source publication establishes consciousness, neural superiority or AGI.

The two conditions have the same 20 failures: zero paired wins, zero losses,
accuracy delta zero and exact paired p-value 1.0. The preregistered superiority
gate failed. Continuity remains optional; the visible route remains the default.
Neither route is promoted to production by this result.

All 140 programs were independently replayed once. Every native verdict agrees
with the original observation. Programs, source checkers and original grades
remain unchanged. The request audit verifies 70 equal first-request pairs and
82 subsequent continuity transitions; no opaque contents are published.

A separate [actual maintenance course](project-work/RESULTS.md) delivered both
required artifacts. Its accountant was reused on later data without a model
request. That demonstrates useful checked work and finite program retention,
while the accuracy and neural-superiority conclusions stay unchanged.

## Provider-free replay

```sh
python research/outcome-learning/reasoning-continuity-09/replay.py
```

This validates commitments, source identities, the outcome journal and complete
paired results without executing programs or calling a provider. Supply a new
workspace to perform native execution. A storage-only cache wrapper can reuse a
read-only Matplotlib font index instead of writing an identical index per job:

```sh
MPLCONFIGDIR=/new/font-cache python -c 'import matplotlib.font_manager'
python research/outcome-learning/reasoning-continuity-09/replay-cached.py \
  /new/native-workspace --font-cache /new/font-cache
```

[The cache amendment](cache-replay-amendment.json) preserves the original replay
source and records successful render controls and denied shared-cache mutation
before the complete replay. The runtime-specific font data stays private. Each
job owns its writable folder; only the read-only index is shared. No original
files are deleted. Native verdicts, rather than byte-identical timing logs,
are the reproducibility claim.

[Complete results](results.json), [transport audit](request-audit.json),
[native replay summary](native-replay-summary.json) and
[all native observations](independent-replay.json.gz) retain the negative result
and its supporting evidence. Provider usage and transport records are host
observations, not independent provider invoices or remote attestations.
