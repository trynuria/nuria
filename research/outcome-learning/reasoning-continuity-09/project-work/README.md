# Actual project maintenance work

Two finite jobs use Nuria data created after the provider model was released:
a new returned version of the archived reporter fixes its already diagnosed
unknown-label defect, and a reusable accountant audits an actual mixed-pricing
inference ledger snapshot. No original archive or provider ledger is edited.

The snapshot includes an in-flight reservation. Missing charges remain reserved
liabilities, and known usage is recomputed under each request's own price
contract. This is configured conservative accounting, not a provider invoice.

Original root-path preflight failures are preserved. They were fixed before
model work by using the executor's declared `inputs/` directory. Both corrected
reference checks pass, including required artifact delivery. Boundary cases are
authored qualifications, distinct from the actual ledger data.

The resulting programs must pass independent host checks before artifact
delivery or skill acquisition. A later actual snapshot tests execution of the
accepted accounting program without new model calls. These two jobs establish
useful delivered work and replay behavior, not broad intelligence superiority.
