# Input-grounded actual project work

Four reports were specified against actual public repository observations before
model inference. The enrollment, protocol and exact runtime archive were public
at [a887934](https://github.com/trynuria/nuria/commit/a887934c2af5dadd92c4d8bc0165dd5ba6bd7018)
before any call. Required report files and independent acceptance were frozen.

| Route                                | Accepted and delivered | Model requests | Configured token cost |
| ------------------------------------ | ---------------------- | -------------- | --------------------- |
| Direct proposal and execution repair | 4/4                    | 4              | $0.055066             |
| Blind challenge and revision         | 4/4                    | 12             | $0.190770             |

Both routes passed all four default reports and their withheld actual-source
checks. The direct route used one proposal per job and needed no repair. It is
selected by the prospective cost rule. The qualification costs $0.245836 total at
configured accounting rates; these are not independently verified invoices.

The inputs contain 24 observed pull requests, 109 complete reachable main-branch
commit records, a different branch's 128 commit records, 12 reported component
identities and 30 recent workflow runs. Workflow-run coverage is explicitly
limited. The component and commit programs also ran on the withheld actual branch
graph. The other checks use labelled subsets of the actual captured collections;
those are functional checks, not independent populations or a broad fresh-task
intelligence comparison. Source ancestry and reported CI do not prove service
health. Missing direct health remains unknown.

`courses.json` retains both complete work receipts, generated programs, checks and
provenance. `artifacts.zip` holds all eight accepted programs, exact report bytes
and delivery receipts. `enrollment.json` retains the specifications, source
projections and host checks. The runtime archive identifies the exact execution
source. `public-freeze-before-models.json` independently records its public blobs.

A separate native replay repeated all eight complete acceptance contracts with
zero mismatches. Identical-job replay returned all eight receipts and artifact
bundles with zero new provider calls or original executions; work journals stayed
byte-identical. `replay-proof.json` records those two distinct checks.

Input structure was missing from the earlier [project work](../project-work-02/),
where two of four reports failed. This new adapter supplies factual paths, types
and sizes from the enrolled inputs, with explicit truncation and invalid-data
handling. It does not expose the host oracle to the model. The jobs and sources
here differ from that earlier run, so 2/4 versus 4/4 is not a controlled causal
estimate of improvement.

These four tasks do not establish model or neural superiority. The broader
[108-task comparison](../course-03/) still ties targeted navigation with static
retrieval at87/108 and fails its prospective improvement gate. No production
worker, financial authority or autonomous deployment was activated.
