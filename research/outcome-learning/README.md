# Outcome-grounded programming

Nuria can execute enrolled Python work, independently check the result, retain
accepted and rejected experience, and use that history in subsequent jobs.
Completed jobs replay without duplicate inference or execution.

The [complete-specification course](course-02) tests transfer to **112 fresh
external tasks across seven work families**. Conditional skill memory passed
83 tasks; ordinary retrieval and a one-reflection learner each passed 81.
**This difference did not establish a reliable advantage.** The existing policy
remains selected. All programs, failures, source tasks, controls and costs are
retained; an independent native replay reproduced all 336 physical outcomes.

The [actual project-work sequence](project-work-01) completes three checked
Nuria audits and replays them with zero new provider requests. This establishes
an executable work loop, separately from the failed superiority gate.

The conditional-memory design draws on the structured playbook approach in
[ACE](https://github.com/ace-agent/ace). This is not an implementation of the ACE
framework or a reproduction of its reported results. Optional policy search
uses [GEPA 0.1.4](https://github.com/gepa-ai/gepa).
