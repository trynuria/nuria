# Historical report delivery

The delivery adapter collected three reports from the previously accepted
project-work course: source drift, reported provider outcomes and reported
release identity. These are the original frozen snapshots, not a fresh service
inspection or a new model comparison.

The collector checked the exact retained program, independent host checker,
input files and each report against the host's pre-existing expected JSON value.
It then preserved the actual report bytes in a content-addressed bundle.
All three identical collection requests replayed the same receipts. No model
calls, program executions or payments were added; the original work journal
remained byte-identical.

- `enrollment.json` binds each task and expected output meaning.
- `artifact-bundles.zip` retains each immutable directory with report and receipt.
- `collection.json` records the first collection and identical repeats.

The underlying reports and their original model runs remain in the parent
course. This delivery result establishes a working artifact handoff; it does
not establish better model reasoning or new learning effectiveness.
