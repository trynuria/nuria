# Checked Nuria work

Three hosted-model jobs ran against actual Nuria source and public endpoint
snapshots. All three passed independent host checks and delivered JSON reports.

| Job                 | Actual work                                                                                                           |
| ------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Source drift        | Compare all enrolled source paths and hashes with the published manifest                                              |
| Reported work audit | Account for every one of forty reported action tasks, keeping unknown costs and acceptance separate                   |
| Release identity    | Compare the endpoint-reported deployed commit with the observed published commit; direct service health stays unknown |

The first pass used three provider requests and $0.033168 at configured token
rates. Each later job automatically received prior executed experience. Running
the identical sequence again returned all three accepted receipts with **zero
new provider requests and zero new executions**.

`enrollment.json` preserves the exact inputs, source hashes, specifications and
independent checkers. `course-01.json` and `course-02.json` retain the first
execution and replay. `reports.json` contains the delivered results. Input
snapshots are historical observations, not a claim of current balances,
deployment identity or direct service inspection.

These are actual computation jobs. The public action projection does not
independently establish payment settlement, and no token trade, human hire or
onchain purchase is represented by this work. It is functional-loop evidence,
not another claim of superiority over the simpler agent.
