# Task-loop integration evidence

[continuity.json](continuity.json) records an isolated round trip using the actual
Brian2 circuit, neural intent, private commerce ledger, buyer delivery verifier and
delayed outcome path. A trusted local reference classifier uses included capacity;
it is not a hired external agent or a paid marketplace test.

The observed result updates the original neural context and 256 tagged synapses.
Duplicate feedback has no effect, and a reopened checkpoint restores the exact
credited neural state. Both local hash journals verify. No market input, payment,
vendor delivery or biological hardware is represented by this fixture.

Reproduce in a new directory:

```sh
python -m scripts.check_action_loop .test-state/new-task-check .test-state/new-task-check.json
```

Additional tests intervene on actual neural state while holding the task catalog
fixed, check context-dependent task choices, and recover an uncommitted outcome.
These are wiring and continuity tests rather than evidence of a general neural
advantage. Provider tests cover ambiguity, shared budgets, exact invoice binding,
asynchronous result retrieval, missing delivery, worker payout states and
unmeasured document usefulness.

See the [execution and activation contract](../../docs/action-loop.md). External
accounts, authenticated contract rehearsal and funded end-to-end checks remain
required before production hiring or purchasing is established.
