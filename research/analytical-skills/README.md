# Checked analytical report reuse

The optional [analytical skill library](../../docs/analytical-skills.md) can retain
the SQL from an accepted procedural-memory episode and execute it against a new,
compatible immutable database. It checks originating evidence and fresh outputs
separately. It does not reuse old answer rows.

This is a finite software capability study. The origin query in the generated
course is a declared conventional aggregation, not a new model-generated answer.
No language-model or neural calls occur in this course. The separate historical
work audit supplies an actual accepted model-origin query for development
integration; that does not turn generated ledgers into real production activity.

## Prospective course

[Protocol 03](protocol-03.json) freezes the report, 12 generated data revisions,
three methods, evaluation rules and exact implementation hashes before challenge
execution. Its SHA256 is:

```text
5130c4fd6aa3b992d55cc75038bcb18bf8d749e61d4652b553bb9454bab7c2e3
```

The challenge includes empty data, NULLs, duplicated rows and IDs, unfamiliar
providers, exact-flag boundaries, utility and payment thresholds, permutation and
sparse data. The generator and report were designed together; fresh generated
rows are not an unseen external task distribution.

All methods receive the same rows and business meaning:

| Method                | Program                           | Additional checks                                                     |
| --------------------- | --------------------------------- | --------------------------------------------------------------------- |
| Qualified skill       | Retained accepted SQL             | Origin evidence, schema contract, durable execution and fresh verdict |
| Exact query cache     | The same original SQL             | Fresh report execution and output check                               |
| Conventional template | Independently written aggregation | Fresh report execution and output check                               |

Schema inspection adds actual query work for the skill library. This is counted;
it is not free reasoning. A tie with the cache or template establishes parity,
not improved intelligence or a neural advantage. No estimated model calls are
substituted for measured calls.

The development course used two separate generated revisions and all three
methods returned correct reports. The original locking failure remains in the
development record. Challenge results are not included in this initial protocol
publication.

## Run and check

The evaluator requires an exact protocol identity and refuses changed frozen
source files. Use a new output directory; preserve incomplete attempts.

```sh
python -m scripts.evaluate_analytical_skills \
  --phase challenge \
  --protocol research/analytical-skills/protocol-03.json \
  --protocol-sha256 5130c4fd6aa3b992d55cc75038bcb18bf8d749e61d4652b553bb9454bab7c2e3 \
  --output /absolute/path/to/new-course

python -m scripts.verify_analytical_skills /absolute/path/to/new-course \
  --protocol-sha256 5130c4fd6aa3b992d55cc75038bcb18bf8d749e61d4652b553bb9454bab7c2e3
```

Independent replay imports neither the executor nor the generator. It checks the
retained memory and skill journals, origin and promotion linkage, fresh source
and request identities, complete course coverage, bounded SQL re-execution and a
separate Python grouping. Hashes identify records; they are not external
execution attestations or proof of a checker's authority.

Changed report semantics, rejected outputs and recovery behavior are protocol
tests. They are separate from the 36 method-case challenge denominator.

Protocol 01 remains retained. Protocol 02 amends failure accounting before any
challenge execution: selections are committed first, completed cases are retained
immediately, and a failed course keeps explicit unexecuted denominators. Incomplete
courses cannot pass verification.

Protocol 03 corrects editorial spacing in Protocol 02 before publication or
challenge execution. It changes no candidate, task, limit or accounting rule.
