# Checked workflows

A goal-directed planner selects a dependency graph over eight enrolled local
operations. The host validates types, source identity, dependencies and a finite
work allowance before executing anything. An independent checker reads the saved
Markdown and rederives its facts from the enrolled snapshot.

The six prospectively declared cases cover provider evidence, delivery versus
reported settlement, bounded audit planning, two labelled synthetic revisions
and a missing primary reader. All three methods—greedy, exact and hosted
model—receive the same operation catalog, source descriptors and observed
failure feedback. The failed reader remains charged when another plan uses the
SQLite mirror. Model requests share the existing finite reasoning allowance.

The source contains forty recent **server-reported** tasks. Included capacity,
recorded utility and delivery do not establish external purchases, independently
verified payments or semantic correctness. Boundary fixtures are explicitly
synthetic. Audit outputs propose rechecks; they do not execute hiring or spend.

This is a finite integration test, not a claim of superiority over exact
planning, general intelligence, neural learning or consciousness. The protocol
and implementation are published before model execution; results are reported
with their complete selected denominator.
