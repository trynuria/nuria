## Evidence

- [Complete safe certificate](certificate.json): every job, diagnostic receipt
  commitments, independent final-output checks, source identities, actual
  chronological library continuity and origin-bound outcome acknowledgments.
- [Terminal checks](terminal-checks.json): unique contracts, exhausted queue and
  catalogue, no open operations or pending library proposals, all nine services
  active, and exact preservation of the earlier 124 tasks and 36 episodes against
  the sealed pre-deployment snapshot. Failure positions use zero-based source
  indices; execution may interleave goal lanes.
- [Collector implementation](../../../scripts/verify_live_composed_skills.py):
  runs against read-only database views and the independent text interpreter,
  without importing the learner or provider. Private buyer records, programs,
  nonces and filesystem paths are excluded from the public certificate.

The running cognition and commerce components are commit
[`8028c3a`](https://github.com/trynuria/nuria/commit/8028c3a14ff0e33ba17f9bf48ca4df438e327446).
Their exact source hashes and deployment times are recorded in the certificate.
Later documentation and replay-tool commits do not change those worker sources.

The certificate preserves the collector's original output. Its shared
`source.independent_interpreter_sha256` field identifies the legacy expression
checker, not this course's text checker. The actual text interpreter is
`scripts/verify_active_skill_results.py`, explicitly identified under
`verification_sources` with SHA256
`e792644271372932752c3d2c5815a3f7278a9ae583f1a7b4c9c2106a89695741`.
The collector imports that interpreter directly for the final-output checks.

The outcome check establishes delivery, retained-rule reuse and a committed
feedback path into the originating neural context. It does **not** reconstruct
synaptic deltas or show that neural routing outperforms a simpler controller.
Journal hashes establish local continuity, not an independent external witness.
Search-work accounting is checked, but the live collector does not re-execute
search or independently attest physical CPU consumption. The separate frozen
[search replication](../reserved/search-replication.json) covers that experiment's
deterministic search records.

Financial execution remained disabled. The inspected commerce ledger contained
zero authorizations, signing requests or settled payment transactions. This
course used included compute and spent no wallet funds; it was not a chain-wide
wallet-balance audit. Existing website layout, styling, scripts and assets were
preserved.
